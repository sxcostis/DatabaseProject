# Database Project
### Project Description

The **Database Project** is a warehouse management application developed using **Python** and the **customtkinter** library.
The application allows users to add, update, delete and search for products in the database.

### Main Features
- **Add Product:** Allows users to add new products to the warehouse.
- **Update Product:** Allows users to modify the information of existing products.
- **Delete Product:** Allows users to remove products from the warehouse.
- **Find Product:** Allows users to find a product from the warehouse.
